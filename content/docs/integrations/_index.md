# Integrations

Koku's REST API enables integrations with external systems for billing,
analytics, and visualization.

## Billing

- **[Lago Billing](lago/)** — Generate itemized invoices from Koku cost data
  using the Lago open-source billing platform.

## Visualization and Reporting

- **[Grafana Dashboards](grafana/)** — Pre-built dashboards showing OpenShift
  cost per project, with three architecture variants (native, proxy, Prometheus).
- **[Power BI](powerbi/)** — Extract cost data into Excel and visualize with
  Power BI Desktop and Power BI Service.
